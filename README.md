# pairwise-ssao

墙角 AO 一圈一圈、角色和地面接触处黑圈、远处噪点：AO 用固定半径；深度重建用最近邻；法线编码丢失；半球采样数固定；噪声用屏幕坐标；AO 和直接光重复乘；透明物体写 AO；多分辨率 AO 直接上采样；相机切换不重置历史；SSAO 在雾后被错误遮挡。render/ssao.py 是核心，tests/test_ssao.py 15个红。要修的是：世界半径；深度双边上采样；法线八面体；自适应采样；世界噪声；AO 去重；透明排除；深度感知上采样；相机重置；雾前应用。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
